DND NERDS - PRODUCTION SECRET HANDLING POLICY

1. Never copy a populated production .env file into F:\DND NERDS PLATFORM\backup.
2. Never place Merchant IDs, access tokens, SMTP passwords, MFA keys, DB passwords,
   payout credentials, or TLS private keys in ordinary project backups or logs.
3. Never pass production secrets as command-line arguments.
4. Provision secrets only on the production host or an approved secret store.
5. Keep source-control templates placeholder-only.
6. Legacy live-payment helper scripts containing LIVE_PAYMENT_ENV_ backup logic
   are disabled by J2M-E and must not be re-enabled.
7. Before production activation, verify:
   - stable HTTPS APP/API domains
   - real payout provider
   - ZarinPal endpoint allowlist
   - production guard
   - finance reconciliation worker
   - controlled low-value validation

Current local provider configuration must remain mock until the activation phase.
