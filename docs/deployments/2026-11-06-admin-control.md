## Entry and capabilities
/admin/control is linked from admin home, game-hub admin and marketplace moderation. Three searchable, status-filtered, paginated resource sections, with detail editor and existing accounts/roles, DM/arena/news, marketplace moderation, sales, subscription, feedback and server-health tools linked.

Tables: edit title/description/system/language/style/levels/schedule/genres/cover/status/capacity/entry method; regenerate invite code; close/hide/restore; permanent deletion through existing signed VTT cleanup job using original host identity. Accepted-member count protects capacity, pending deletion blocks resurrection, membership revocation follows hide/close/delete. Offline bridge leaves table hidden and deletion queued; retry remains available. Invitation hash is not exposed in resource responses.

Stores: edit name, slug, description, category, status and featured flag. Existing scheduled featured expiry is retained on unrelated edits. Deletion archives and removes public catalog availability, with restoration through status. No deletion of order, payment or ledger history.

Products: edit metadata, category/type/brand/preparation/image/status; publish only with active seller/store and valid active variant. Variants expose name/SKU/options, price (UI toman, API rial), stock, order limit, status and timed discount. Stock never falls below active reservations; database price history and stock movements capture actor/reason. Archive/remove is restorable. Admins may read draft media only when linked to an actual product; unrelated customer uploads remain inaccessible.

Writes require existing active SUPER_ADMIN or MARKETPLACE_ADMIN, password reauthentication and reason; SUPPORT remains read-only. Delete additionally requires exact current name. Server-side allowlists reject ownership injection. Every admin write is audited without passwords. Optional expectedVersion prevents stale edits; UI sends exact stored versions, including variant snapshot version. Refreshing variant props remounts its form to avoid resubmitting old prices with fresh versions.
