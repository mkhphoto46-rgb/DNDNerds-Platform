# Navigation and content design
Implement the user's detailed November 4 request on the current production baseline f488ed5 (runtime released from 08321a4), retaining the supplied blue/cyan/gold design.
Games opens /games with exactly three cards: my tables /play, find game /find-game, create /create-game. Find game lists published open and invite-only tables and existing visible DM profiles. Draft/hidden/closed tables stay out of discovery; invitation and membership authorization remains enforced. Private campaign metadata becomes public per explicit request; never expose invite hashes/codes.
Replace Community with Knowledge /knowledge: stories-and-modules together, homebrew, rules, equipment guides. Category landing pages list articles; separate readable articles include substantive original Persian content. Homebrew supports authenticated author-owned server CRUD and publishing. Original articles are editorial, not official translations; rules identify SRD edition and link official references.
Home loses redundant store and bottom chat launcher; header chat remains. Existing DM Home preview is labeled accurately and moves under Games, knowledge preview links to articles. XP becomes wide, larger and ornamental without its enclosing colored box. Market categories are a single horizontal scroll rail, filters collapsed by default. Mobile cards, panels, text and navigation must not overlap.
Use existing Next/React and PostgreSQL; no new dependencies, no payment or VTT changes. Add one isolated article table migration without modifying existing rows. Work in a source snapshot to preserve unrelated concurrent work. Keep a verified pre-release backup and rollback path before any authorized production release.
