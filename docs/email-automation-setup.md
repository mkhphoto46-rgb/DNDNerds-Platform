# راه‌اندازی تأیید ایمیل و بازیابی رمز

سایت اکنون پیوند یک‌بارمصرف تأیید ایمیل و بازیابی رمز را می‌سازد. برای ارسال واقعی، یک فرستندهٔ ایمیل لازم است. تا پیش از تنظیم آن، ثبت‌نام در حالت رایگان Wispbyte مانند قبل به تأیید مدیر نیاز دارد و صفحه‌های درخواست ایمیل، نبود سرویس را اعلام می‌کنند. تغییر رمز از داخل حساب به سرویس ایمیل نیاز ندارد.

## گزینهٔ پیشنهادی: Brevo از راه HTTPS

1. در Brevo حساب بساز و فرستندهٔ ایمیل را تأیید کن. بهتر است آدرس فرستنده روی دامنه‌ای باشد که مالک آن هستی.
2. در Brevo یک API key مخصوص ارسال ایمیل تراکنشی بساز. کلید را در گفتگو، GitHub یا فایل‌های عمومی قرار نده.
3. در فایل خصوصی محیط سرور Wispbyte و نسخهٔ محلی پشتیبان آن، این مقادیر را اضافه کن:

```dotenv
EMAIL_PROVIDER=brevo
BREVO_API_KEY=<secret API key>
EMAIL_FROM=<verified sender address>
PUBLIC_APP_URL=https://dndnerds.wispbyte.app
```

4. سرور را راه‌اندازی دوباره کن. یک حساب آزمایشی با ایمیل خودت بساز، دریافت پیوند و تأیید خودکار را بررسی کن. سپس «فراموشی رمز» را آزمایش کن. اگر Brevo ارسال را نپذیرد، کاربر ثبت می‌شود اما منتظر تأیید می‌ماند و می‌تواند از صفحهٔ `/verify-email` پیوند تازه درخواست کند.

راه جایگزین SMTP نیز پشتیبانی می‌شود: `EMAIL_PROVIDER=smtp` و `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `EMAIL_FROM` را تنظیم کن. برای SMTP روی هاست، باز بودن اتصال خروجی پورت ایمیل لازم است.

پیوند تأیید ۶۰ دقیقه و پیوند بازیابی ۳۰ دقیقه اعتبار دارد. هر پیوند فقط یک بار مصرف می‌شود. تأیید ایمیل، حساب در انتظار را فعال می‌کند؛ حساب‌های مسدودشده یا تعلیق‌شده را فعال نمی‌کند. تغییر یا بازیابی رمز، همهٔ نشست‌های قبلی را می‌بندد.
