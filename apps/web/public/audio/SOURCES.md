# Town ambience sources

- `village-market.ogg`: [Market recorded audio.ogg](https://commons.wikimedia.org/wiki/File:Market_recorded_audio.ogg), Aishatu98, CC0 1.0. Original recording, unmodified.
- `inn-crowd.ogg`: [Restaurant ambience.ogg](https://commons.wikimedia.org/wiki/File:Restaurant_ambience.ogg), stephan, public domain. Original recording, unmodified. Used as the inn's crowd ambience.

Both tracks are played only after the visitor enables ambient sound. The UI sets the volume to 22% and stops playback when sound is disabled or the scene unmounts.
